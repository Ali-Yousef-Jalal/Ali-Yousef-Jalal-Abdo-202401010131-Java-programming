## Tutorial Summary (Week 1–10)

| Folder | Topic Covered |
|---|---|
| tutorial_1 | Introduction to Java & OOP basics – creating a Student class with attributes, constructor, and a main program to test it |
| tutorial_2 | Practicing class design – Student class with a separate Main class to create and test objects |
| tutorial_3_4 | Working with multiple related classes (Person, Student, Lecturer) – introduction to class relationships and object interaction |
| tutorial_5 | Reinforcing class and object concepts with Student class – constructors and object testing |
| tutorial_6 | Expanding on class relationships – Employee, Lecturer, and Person classes, practicing attributes and methods across related classes |
| tutorial_7 | Practicing inheritance – Appliance as a parent class with Refrigerator and WashingMachine as subclasses |
